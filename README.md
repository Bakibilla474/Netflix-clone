# Streaming Landing Page

A responsive landing-page concept built with HTML and CSS. It recreates a streaming service hero section and a TV feature layout as a frontend practice project.

## Included

- Responsive hero section with an image background and readable contrast overlay
- Semantic page structure and labeled email field
- Flexible sign-in and call-to-action controls
- TV feature layout with a decorative, muted video layer

## Run locally

Open `index.html` in a modern browser. No build step is required.

## Scope

This is a static UI demo. Sign-in and membership actions do not connect to a service, and the email field does not submit data. The page is not affiliated with or endorsed by Netflix.
